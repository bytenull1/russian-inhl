# Русский перевод для Isolated Inhale

Плагин для BepInEx 5, который добавляет **русский** в собственный список языков игры, рядом с
официальными. Сделан для версии игры **0.8.9**.

- Файлы игры не заменяются, поэтому обновление игры не ломает ни игру, ни перевод.
- Строка, которой ещё нет в переводе, показывается на английском.
- Удалять плагин безопасно, без него игра возвращается к английскому.

## Установка

1. Скачайте [BepInEx 5](https://github.com/BepInEx/BepInEx/releases/latest) (файл `BepInEx_win_x64_5.x.x.zip`)
   и распакуйте его в папку игры.
2. Скопируйте файл `RussianTranslation.dll` в `BepInEx/plugins/`.
3. Запустите игру и выберите **Settings → Language → Russian**.

Выбор сохраняется вместе с остальными настройками игры. Язык можно сменить и в главном меню, и в
меню паузы. Чтобы удалить перевод, удалите папку плагина - игра вернётся к английскому.

## Как это работает

Кнопка **Russian** - копия кнопки языка из самой игры. Она стоит по алфавиту, между Romanian и
Spanish.

Плагин берёт английские строки игры и заменяет их русскими. Строки без перевода остаются на
английском. Так после обновления игры новые строки видны по-английски, пока их не переведут.

Если в переводе есть строки, которых в игре больше нет, плагин их пропускает. Они перечисляются в
логе.

Перевод встроен в DLL. Каждый раз, когда загружается русский, плагин пишет сводку в
`BepInEx/LogOutput.log`:

```
[Info   :Russian Translation] Russian: 554/554 strings translated (0 in English, 0 obsolete, 0 placeholder warnings) from built-in translation.
```

Часть текста зашита в код игры (например, "Couldn't load selected save file"). Его нет в языковых файлах, поэтому он не переводится ни на один язык, и этот плагин тоже его не переводит.

## Для переводчиков

Исходник перевода - [`RussianTranslation/Resources/Russian.json`](RussianTranslation/Resources/Russian.json).
Формат тот же `ключ: текст`, что и у языковых файлов игры, и порядок ключей тот же, что в английском
файле игры.

**Проверка правок без пересборки:** положите свой `Russian.json` рядом с `RussianTranslation.dll`.
Плагин возьмёт перевод из него, а не встроенный. Чтобы загрузить правки, снова нажмите **Russian**
в меню языков - перезапускать игру не нужно. Если файл не читается (например, ошибка в JSON), в логе
будет сообщение об ошибке, а игра переключится на встроенный перевод.

**Сохраняйте разметку:**

| Разметка | Что это | Правило |
| --- | --- | --- |
| `<Key>`, `<Task>`, `<Error>`, `<Command>`, `<Inactive>`, `<Tutorial>`, `<Secret>`, `<Scary>` ... `</>` | цвета игры | Можно переставлять. Оставляйте там же, где они стоят в английском. |
| `<color=#...>`, `</color>`, `<b>`, `</b>` | TextMeshPro | То же, что выше. |
| `<Credits>`, `<Name>`, `<Nickname>`, `<Value>`, `<KeyBind>`, `<Index>`, `<SaveName>`, `<Success>`, `<0>`...`<5>` | значения, которые подставляет игра | Ровно те же, что в английском. Без нужного значение пропадёт, лишний покажется как текст. |
| `CMDS_*` | слова, которые игрок пишет боту | Делайте их короткими и непохожими друг на друга. Бот принимает совпадение примерно от 70%. |

**После обновления игры:**

1. Установите `WriteReport = true` в `BepInEx/config/com.bytenull1.russiantranslation.cfg`.
2. Запустите игру и выберите русский. Рядом с DLL появится `untranslated.json` с английским текстом
   всех ещё не переведённых ключей.
3. Переведите эти ключи в `Russian.json`. Проверьте и английский текст, изменившийся у
   существующих ключей: плагин такое не замечает.

**Перед коммитом запустите линтер:**

```bash
python tools/check_translation.py
```

Если у вас есть экспортированный английский файл игры (например, через AssetRipper,
`Resources/Translations/English`), линтер также сообщит об отсутствующих и устаревших ключах и о
несовпадении подстановок:

```bash
python tools/check_translation.py --english English.json
```

## Сборка

Проект компилируется c библиотеками самой игры. Их нельзя распространять, скопируйте их, как описано
в [`RussianTranslation/lib/README.md`](RussianTranslation/lib/README.md).

```bash
dotnet build RussianTranslation/RussianTranslation.csproj -c Release
```

Результат - `RussianTranslation/bin/Release/netstandard2.1/RussianTranslation.dll`. Скопируйте его в
`BepInEx/plugins/`. Пока игра запущена, скопировать не получится.
